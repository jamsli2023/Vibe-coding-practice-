# 项目 02：二进制转换器

> 对应必修1《数据与计算》"数据的编码"：做一个进制转换交互工具，理解计算机为什么用二进制。

## 学习目标

- 理解二进制与十进制的相互转换规则
- 学会让 AI 生成带输入校验的交互界面
- 练习"迭代式提问"：先最小版本，再逐步加功能

## 任务卡

### 基础任务

```text
请用单个 HTML 文件实现一个进制转换器：
【功能1】输入十进制正整数（0~255），点击"转换"显示对应 8 位二进制
【功能2】输入 8 位二进制（只允许 0 和 1），点击"转换"显示对应十进制
【校验】输入非法内容时给出中文错误提示，不要用 alert 弹窗，直接在页面显示
【界面】两个输入区清晰分开，全中文
```

### 挑战任务（任选）

1. 增加十六进制支持（0~FF）
2. 用 8 个可点击的"灯泡"可视化二进制每一位（点亮=1），点击切换并实时显示十进制值
3. 显示每一个二进制位的权值（128 64 32 16 8 4 2 1）

### 验收要求

- [ ] 输入 100 能得到 01100100，输入 01100100 能得到 100
- [ ] 输入 `10a1` 这类非法二进制时页面有友好提示
- [ ] 能口头解释：为什么 8 位二进制最大是 255？

## 提示卡（卡住时看）

- 十进制转二进制：`Number(10).toString(2)` → `"1010"`，可用 `padStart(8,'0')` 补足 8 位
- 二进制转十进制：`parseInt('01100100', 2)`
- 校验二进制：`/^[01]{8}$/.test(input)`
