# 项目 03：班级数据看板

> 综合实战：用 AI 生成一个班级成绩数据可视化看板，体验"数据 → 图表 → 洞察"的完整链路。

## 学习目标

- 体验用 AI 快速生成数据可视化页面（Vibe Coding 最擅长的场景）
- 理解"数据文件 + 展示页面分离"的工程思想
- 学会基于数据提出问题并验证

## 任务卡

### 基础任务

本目录已提供示例数据 `data.csv`（某班 6 名学生的三次考试成绩）。

```text
请用单个 HTML 文件实现一个"班级成绩看板"：
【数据】页面内嵌以下 CSV 数据（我会贴给你）
【图表】用 Chart.js（CDN 引入）绘制：
  1. 每位学生三次成绩的折线图（看进步/退步趋势）
  2. 每次考试各科平均分的柱状图
【指标】页面顶部显示 3 个统计卡片：班级人数、全班平均分、最高总分学生姓名
【界面】深色主题，全中文，标题"高二(3)班 数据看板"
```

### 挑战任务（任选）

1. 增加"选择学生"下拉框，单独显示某学生的成绩雷达图
2. 把数据改为从 `data.csv` 用 fetch 读取（注意：需通过本地服务器打开，如 `python3 -m http.server`）
3. 自动找出"进步最大"的学生并在看板上标注

### 验收要求

- [ ] 两个图表正确渲染，数值与数据一致
- [ ] 能说出从图表中发现的 1 条结论（如"谁的语文进步最快"）
- [ ] 能指出代码中"把 CSV 数据转成图表数据"的关键函数

## 提示卡（卡住时看）

- Chart.js CDN：`https://cdn.jsdelivr.net/npm/chart.js`
- 折线图核心：`new Chart(ctx, { type:'line', data:{ labels:[...], datasets:[...] } })`
- 图表不显示？F12 看控制台，常见原因是 canvas 的 id 对不上或 CDN 加载失败
