# 项目 01：猜数字游戏

> 第一个 Vibe Coding 实战：让 AI 帮你写出一个完整可玩的小游戏，理解"随机数 + 循环判断 + 事件处理"。

## 学习目标

- 学会用「四要素 Prompt」描述一个程序需求
- 理解随机数生成、条件判断、DOM 事件的基本逻辑
- 学会用浏览器控制台（F12）查看报错

## 任务卡

### 基础任务

向 AI 发出如下 Prompt（可修改措辞，但四要素要齐全）：

```text
请用【单个 HTML 文件】实现一个猜数字游戏，浏览器直接打开就能玩：
【规则】程序随机生成 1~100 的整数；玩家在输入框中输入猜测，点击"猜"按钮后，
页面提示"大了"/"小了"/"猜对了"；记录并显示当前猜测次数。
【界面】全中文，简洁美观，含标题、输入框、按钮和提示区。
【验收】猜对后显示总次数，并提供"再来一局"按钮重置游戏。
```

把 AI 生成的代码保存/粘贴到本目录的 `index.html`，浏览器打开验证。

### 挑战任务（任选）

1. 限制最多猜 7 次，超限游戏失败并公布答案
2. 增加难度选择：简单(1~50) / 普通(1~100) / 困难(1~200)
3. 增加"历史猜测记录"列表

### 验收要求

- [ ] 游戏可完整玩通一局
- [ ] 能指出代码中"生成随机数"和"判断大了/小了"的具体行
- [ ] 记录你使用的 Prompt 轮数

## 提示卡（卡住时看）

- 随机数：`Math.floor(Math.random() * 100) + 1`
- 读输入框：`document.getElementById('guess').value`
- 看报错：F12 → Console 面板
