# 讲义 1：什么是 Vibe Coding

## 1. 从"写代码"到"说代码"

过去，程序员需要用编程语言（Python、JavaScript……）逐行把想法"翻译"给计算机。
Vibe Coding 是一种新的开发方式：**用自然语言向 AI 描述需求，由 AI 生成代码，人负责描述、验证与迭代**。

> 📖 术语来源：2025 年 2 月，OpenAI 前研究总监 Andrej Karpathy 提出
> "There's a new kind of coding I call 'vibe coding'——你完全沉浸在感觉里，拥抱指数级增长，甚至忘记代码本身的存在。"

## 2. 核心工作循环

```
描述需求 → AI 生成代码 → 运行验证 → 反馈修改 → 再验证 → 完成
   ↑                                            │
   └────────────── 不满意就继续迭代 ←────────────┘
```

## 3. Vibe Coding ≠ 不学编程

AI 负责"手"，学生仍然要负责"脑"。没有以下能力，AI 生成的代码你根本无法驾驭：

| 能力 | 在 Vibe Coding 中的作用 |
|------|------------------------|
| 需求拆解 | 把"我要一个游戏"拆成 AI 能理解的具体步骤 |
| 算法思想 | 判断 AI 给出的方案是否正确、效率如何 |
| 代码阅读 | 看懂生成代码的逻辑，找出问题所在 |
| 调试验证 | 运行程序、设计测试用例、定位错误 |

## 4. 适用场景与边界

**适合**：网页小工具、小游戏、数据可视化、原型验证、学习新语法。

**不适合直接"凭感觉"**：涉及个人隐私数据的系统、安全关键代码（支付、登录）、无验证直接上线的程序。

> ⚠️ 安全提醒：AI 生成的代码必须先理解再使用，尤其是从网络请求、存储用户输入的部分。绝不把个人真实信息（姓名、电话、身份证号）写进演示代码。

## 5. 课堂讨论

1. 用 AI 生成代码和"抄别人的作业"有什么本质区别？
2. 如果 AI 生成的程序有 bug，你会怎么描述这个 bug 让 AI 修复？
3. 什么情况下你会选择手写代码而不是让 AI 生成？
